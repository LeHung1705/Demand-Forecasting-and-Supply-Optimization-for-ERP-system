# =====================================================================
# Backend Python dependencies (FastAPI + DuckDB)
#
# Mục tiêu:
# - Chạy API tại: http://127.0.0.1:8000/api/v1/...
# - Backend chạy chế độ CSV-only (không dùng MySQL/SQLAlchemy)
# - Truy vấn CSV hiệu năng tốt bằng DuckDB (có cache file .duckdb)
#
# ---------------------------------------------------------------------
# CÁCH CHẠY BACKEND (Windows / PowerShell)
# 1) Vào thư mục backend:
#    cd d:\FrontendERP\Demand-Forecasting-and-Supply-Optimization-for-ERP-system\backend
#
# 2) Tạo virtualenv (chỉ cần 1 lần):
#    python -m venv venv
#
# 3) Kích hoạt venv:
#    .\venv\Scripts\Activate.ps1
#
# 4) Cài dependencies:
#    python -m pip install -r requirements.txt
#
# 5) (Tuỳ chọn) Set đường dẫn CSV / DuckDB cache nếu bạn để data ở chỗ khác:
#    # Mặc định đã trỏ tới:
#    # - CSV:    backend/app/data/original_data.csv
#    # - DuckDB: backend/.cache/app.duckdb
#    # Nếu muốn override:
#    $env:CSV_PATH   = "D:\path\to\original_data.csv"
#    $env:DUCKDB_PATH = "D:\path\to\app.duckdb"
#
# 6) Chạy server:
#    python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
#
# Ghi chú:
# - Trên Windows, tránh dùng --reload nếu bạn gặp lỗi lock file DuckDB.
# - Nếu gặp lỗi thiếu thư viện, đảm bảo bạn đang chạy đúng python trong venv.
# =====================================================================
